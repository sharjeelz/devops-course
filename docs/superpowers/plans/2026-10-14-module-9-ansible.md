# Module 9 (Ansible) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Configure the hosts that aren't on Kubernetes with Ansible: Module 7's Linkly server and
a bastion in front of it, as roles (`common`, `bastion`, `docker`, `linkly`), with the server's
database password in Ansible Vault, tested for idempotence in CI. Seven lessons.

**Verification without AWS (the user's standing choice):** a local lab in Docker:
- a **control** container (ansible-core, ansible-lint, an SSH client);
- a **bastion** and a **web1** host: Amazon Linux 2023 (the EC2 image) running systemd and sshd,
  `web1` reachable only through the bastion (separate networks), and running Docker inside itself
  for Linkly's containers;
- `app/linkly/ansible/lab/rehearse.sh` runs the playbook, checks Linkly answers, runs it again and
  requires `changed=0`, and checks the SSH hardening and the bastion path.

The spike before the plan proved both risky parts on Docker Desktop: systemd + sshd + Docker in
an `amazonlinux:2023` container (privileged, `--cgroupns=host`, a volume for `/var/lib/docker`),
and ansible-core 2.21 managing its Python 3.9.

**Tech Stack:** ansible-core 2.21.5, ansible-lint 26.10.1, Python 3.13 control image, Amazon Linux
2023 hosts, Docker Compose plugin v5.6.0 (as Module 6), no Galaxy collections (only `ansible.builtin`).

**Spec:** `docs/superpowers/specs/2026-10-14-course-design.md`, row 9: "Configure the non-Kubernetes
hosts (e.g. a bastion); roles | Chef/Puppet, cloud-init".

## Global Constraints
- Lesson header with a **Cost** line; local lessons are free, the AWS lesson costs Module 7's ~$0.02/h.
- `compose.yaml` stays backward compatible: with no `LINKLY_DB_PASSWORD`, the password is still
  `linkly` (smoke tests and Modules 1–7 unchanged).
- No secret in Git in plain text: the lab's vault file is generated by the rehearsal (and by the
  learner), never committed.

## Planned rulings
- **Only `ansible.builtin` modules** (systemd unit + `docker compose` instead of
  `community.docker`): no Galaxy dependency to pin or break, and nothing extra on the host.
  Cost if wrong: the learner doesn't see collections in practice; lessons 3 and 7 name them.
- **No Molecule:** the rehearsal does what Molecule would (converge, idempotence, verify) with
  the same lab; Molecule is named in lesson 5 and the landscape. Cost if wrong: one more tool to
  meet later.
- **Terraform hands over to Ansible** with one variable: `configure_with_ansible = true` in
  `envs/dev` turns off the server's user_data (module `server` gets `user_data_enabled`).
- **DB password must be letters and digits** (asserted by the role), because it goes into
  `DATABASE_URL` unescaped. Cost if wrong: none; a clear error instead of a broken URL.

## Review Focus
1. Second run must report `changed=0` on every host (handlers and templates idempotent).
2. sshd hardening must never lock you out: config validated with `sshd -t` before it's applied.
3. `web1` reachable only via the bastion (ProxyJump), as a private EC2 host would be.
4. The vaulted password reaches Postgres and `DATABASE_URL` and never appears in Ansible's output (`no_log`).
5. Defaults of `compose.yaml` and the Terraform server module unchanged.
