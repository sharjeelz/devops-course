# Module 2 (CI with GitHub Actions) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On every push and pull request, Linkly is linted, tested in its own test images and smoke-tested as a whole stack. On `main` and on version tags, its three images are published to GitHub Container Registry with meaningful tags. Seven lessons teach the pipeline as the learner builds it.

**Architecture:**
- **One workflow:** `.github/workflows/ci.yml` has four jobs: `lint` (Ruff) → `test` (matrix over api and worker, building each Dockerfile's `test` stage with the GitHub Actions cache) → `smoke` (`app/linkly/smoke-test.sh`) → `publish` (matrix over api, worker and web).
- **Publish rules:** publish runs only on `push`, gets `packages: write`, and tags images with metadata-action: semver from `v*` tags, `sha-<short>`, and `main`.
- **Version visible at runtime:** the API reports the version it was built from at `/healthz`, via a `VERSION` build argument.

**Tech Stack:** GitHub Actions (ubuntu-24.04 runners), actions/checkout@v7, astral-sh/ruff-action@v3 (Ruff 0.17.0), docker/setup-buildx-action@v4, docker/build-push-action@v7, docker/login-action@v4, docker/metadata-action@v6, GHCR, actionlint 1.7.12 (local check).

**Spec:** `docs/superpowers/specs/2026-10-14-course-design.md` (module map row 2: "Lint, test, build images, push to GHCR, versioning; landscape: Jenkins, GitLab CI").

## Global Constraints

- **Lesson format:** same as Modules 0–1, checked by the module format check, including the "Start from" checkpoint in every lesson header (`checkpoint/02-ci`).
- **Action versions:** pinned to the current majors listed above; never `@master` or `@main`.
- **Least privilege:** the workflow defaults to `permissions: contents: read`; only `publish` gets `packages: write`; nothing publishes on `pull_request` (forks' PRs get no write token anyway).
- **Image names must be lowercase:** `ghcr.io/<owner>/linkly-<service>`, with the owner lowercased in the workflow because forks can have capitals.
- **`checkpoint/02-ci` is not changed:** it is where learners start, lint findings included, which lesson 3 relies on.
- **No GitHub repository is created or pushed to by this plan.** GitHub-side behaviour is verified when the author publishes; this plan verifies locally with actionlint plus the jobs' own commands.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A fork owner with capital letters.** `ghcr.io/SharjeelZ/...` is an invalid reference; the workflow must lowercase it. Pinned in Task 3 (`${GITHUB_REPOSITORY_OWNER,,}`, checked by reading the generated env in a local bash run).
2. **A pull request from a fork.** It must lint, test and smoke but never try to publish. Pinned in Task 3 (`if: github.event_name == 'push'`, checked by actionlint and review).
3. **Two pushes in quick succession.** The older run is cancelled (`concurrency` on the ref) rather than racing to publish. Pinned in Task 3.
4. **"Which version is actually running?"** `/healthz` reports the build's version, and `dev` when built locally without one. Pinned in Task 1 (unit test) and Task 3 (local `--build-arg` check).
5. **Lint config that differs between a learner's editor and CI.** Ruff reads `app/linkly/ruff.toml` both locally and in the action. Pinned in Task 2 (the same command locally).

### Task 3: The workflow

**Files:** Create `.github/workflows/ci.yml`.

- [ ] **Step 1: Write it.**

```yaml
# Linkly's pipeline (module 2): lint → test → smoke → publish.
# Runs on pull requests and on pushes to main; publishes images only on pushes (main and v* tags).
name: CI

on:
  push:
    branches: [main]
    tags: ["v*"]
  pull_request:

permissions:
  contents: read

concurrency:
  group: ci-${{ github.ref }}
  cancel-in-progress: true

jobs:
  lint:
    runs-on: ubuntu-24.04
    steps:
      - uses: actions/checkout@v7
      - uses: astral-sh/ruff-action@v3
        with:
          version: "0.17.0"
          src: app/linkly

  test:
    runs-on: ubuntu-24.04
    strategy:
      matrix:
        service: [api, worker]
    steps:
      - uses: actions/checkout@v7
      - uses: docker/setup-buildx-action@v4
      - name: Build the test stage
        uses: docker/build-push-action@v7
        with:
          context: app/linkly/${{ matrix.service }}
          target: test
          load: true
          tags: linkly-${{ matrix.service }}:test
          cache-from: type=gha,scope=${{ matrix.service }}-test
          cache-to: type=gha,mode=max,scope=${{ matrix.service }}-test
      - name: Run the tests
        run: docker run --rm linkly-${{ matrix.service }}:test

  smoke:
    needs: [lint, test]
    runs-on: ubuntu-24.04
    steps:
      - uses: actions/checkout@v7
      - name: Build, start and use the whole stack
        run: app/linkly/smoke-test.sh

  publish:
    needs: smoke
    if: github.event_name == 'push'
    runs-on: ubuntu-24.04
    permissions:
      contents: read
      packages: write
    strategy:
      matrix:
        service: [api, worker, web]
    steps:
      - uses: actions/checkout@v7
      - name: Image name (registry names must be lowercase)
        run: echo "IMAGE=ghcr.io/${GITHUB_REPOSITORY_OWNER,,}/linkly-${{ matrix.service }}" >> "$GITHUB_ENV"
      - uses: docker/setup-buildx-action@v4
      - uses: docker/login-action@v4
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}
      - id: meta
        uses: docker/metadata-action@v6
        with:
          images: ${{ env.IMAGE }}
          tags: |
            type=semver,pattern={{version}}
            type=semver,pattern={{major}}.{{minor}}
            type=sha
            type=raw,value=main,enable={{is_default_branch}}
      - uses: docker/build-push-action@v7
        with:
          context: app/linkly/${{ matrix.service }}
          push: true
          tags: ${{ steps.meta.outputs.tags }}
          labels: ${{ steps.meta.outputs.labels }}
          build-args: VERSION=${{ steps.meta.outputs.version }}
          cache-from: type=gha,scope=${{ matrix.service }}
          cache-to: type=gha,mode=max,scope=${{ matrix.service }}
```

- [ ] **Step 2: Verify locally.**

- [ ] **`03-lint-test-matrix.md` "# Lint, test, and a matrix"**

- [ ] **`04-smoke-in-ci.md` "# The whole stack in CI"**
