# EC2

> **You need:** Lesson 2 (`VPC_ID` and `SUBNET_ID` set) · **Time:** ~60 min · **Cost:** about $0.02 per hour while the instance runs (t3.micro + public IPv4) · **Start from:** `checkpoint/06-aws`

## Why this matters

A virtual machine in the cloud is the most basic thing you can run, and still the right answer
surprisingly often. You'll start one, lock it down so only you can reach it, and SSH in: the
cloud version of Module 0's Linux box.

## Concept

- **Instance:** a VM. Its **instance type** sets CPU and memory: `t3.micro` has 2 vCPUs and
  1 GiB. `t` types are *burstable*: they run on CPU credits and slow down if you use them up.
- **AMI:** the disk image it boots from. AWS publishes the latest Amazon Linux 2023 AMI ID in a
  public SSM parameter, so you never hard-code an ID that changes every month.
- **Key pair:** AWS keeps the public key, and you download the private key *once*. Lose it and you
  lose SSH access; leak it and so does everyone else.
- **Security group:** a stateful firewall around the instance. Allow only what you need, from
  where you need it: here SSH (22) and Linkly (8080), **only from your own IP** (`/32`).
- **IMDSv2** (`HttpTokens=required`): the instance's metadata service, which hands out the
  instance role's credentials (lesson 5), only answers requests with a session token. That stops
  a whole class of attacks that trick a server into fetching that URL.
- **EBS:** the instance's disk. It's billed while it exists, and is deleted with the instance by default.

## Example

```bash
mkdir -p ~/.ssh && rm -f ~/.ssh/linkly-course.pem     # a key left from an earlier run is read-only
aws ec2 create-key-pair --key-name linkly-course --key-type ed25519 \
  --tag-specifications 'ResourceType=key-pair,Tags=[{Key=Project,Value=linkly-course}]' \
  --query KeyMaterial --output text > ~/.ssh/linkly-course.pem
chmod 400 ~/.ssh/linkly-course.pem       # outside the repo: never commit a private key

MY_IP=$(curl -s https://checkip.amazonaws.com)
SG_ID=$(aws ec2 create-security-group --group-name linkly-course --vpc-id "$VPC_ID" \
  --description "Linkly course: SSH and web from my IP only" \
  --tag-specifications 'ResourceType=security-group,Tags=[{Key=Project,Value=linkly-course}]' \
  --query GroupId --output text)
aws ec2 authorize-security-group-ingress --group-id "$SG_ID" --protocol tcp --port 22 --cidr "$MY_IP/32"
aws ec2 authorize-security-group-ingress --group-id "$SG_ID" --protocol tcp --port 8080 --cidr "$MY_IP/32"

AMI_ID=$(aws ssm get-parameters --names /aws/service/ami-amazon-linux-latest/al2023-ami-kernel-default-x86_64 \
  --query 'Parameters[0].Value' --output text)

INSTANCE_ID=$(aws ec2 run-instances --image-id "$AMI_ID" --instance-type t3.micro \
  --key-name linkly-course --subnet-id "$SUBNET_ID" --security-group-ids "$SG_ID" \
  --metadata-options HttpTokens=required \
  --tag-specifications 'ResourceType=instance,Tags=[{Key=Project,Value=linkly-course},{Key=Name,Value=linkly-course}]' \
                       'ResourceType=volume,Tags=[{Key=Project,Value=linkly-course}]' \
  --query 'Instances[0].InstanceId' --output text)
aws ec2 wait instance-running --instance-ids "$INSTANCE_ID"
PUBLIC_IP=$(aws ec2 describe-instances --instance-ids "$INSTANCE_ID" \
  --query 'Reservations[0].Instances[0].PublicIpAddress' --output text)

ssh -i ~/.ssh/linkly-course.pem ec2-user@"$PUBLIC_IP"
```

On the instance: `cat /etc/os-release`, `free -h`, `df -h`. It's the same Linux skills as Module 0.
(If SSH times out, your IP may have changed since you created the rule: compare
`curl -s https://checkip.amazonaws.com` with the security group's rule.)

## Check yourself

1. Why look up the AMI through an SSM parameter instead of copying an AMI ID?

<details><summary>Answer</summary>

AMI IDs differ per region and change with every new image. The public parameter always points
at the latest Amazon Linux 2023 image in your region, so the command keeps working.

</details>

2. What's wrong with allowing SSH from `0.0.0.0/0`?

<details><summary>Answer</summary>

Every scanner on the internet can try to log in, all day. Limiting it to your own `/32` removes
nearly all of that exposure; Systems Manager Session Manager can remove the open port entirely.

</details>

3. Which parts of this lesson keep costing money if you walk away?

<details><summary>Answer</summary>

The running instance, its public IPv4 address and its EBS disk. The VPC, subnet, security group
and key pair cost nothing.

</details>
